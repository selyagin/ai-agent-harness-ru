# Модуль 8. CLI-интерфейс

CLI позволяет запускать harness из Терминала и получать воспроизводимый результат. Пользователь передаёт задачу и опции, а приложение показывает ход работы и финальный отчёт.

## Пример запуска

```bash
npm run dev -- --task "Найди обработчик формы" --sandbox local
```

## Минимальные аргументы

- `--task` — задача для агента; обязательна.
- `--sandbox` — среда исполнения, например `local` или `memory`.
- `--model` — идентификатор модели; не храните в нём API-ключ.

## Поведение CLI

1. Проверить аргументы до запуска модели.
2. Создать sandbox и инструменты.
3. Загрузить system prompt и при наличии `AGENTS.md`.
4. Вывести события: поиск, чтение, вопрос, запрос approval, проверка.
5. Закрыть sandbox в `finally`, даже если произошла ошибка.

## Ошибки

Ошибка должна быть полезной: показать, какого аргумента не хватает или какая команда не разрешена. Не выводите токены и полный внутренний prompt.

## Практика

Составьте три запуска: с корректной задачей, без `--task` и с неизвестным sandbox. Опишите ожидаемый вывод каждого.
