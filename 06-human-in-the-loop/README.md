# Модуль 6. Человек в цикле

## Когда агент обязан спросить

Если задача неоднозначна или действие меняет данные, агент не должен угадывать. Он задаёт вопрос до вызова инструмента. Например: «Какой пакетный менеджер использовать?» или «Разрешить перезаписать файл config.ts?»

## Структурированный вопрос

Вместо длинного открытого сообщения используйте tool `askUser`:

```ts
type AskUser = {
  question: string;
  options: string[]; // от 2 до 4 вариантов
};
```

Пример: вопрос `Как запустить проверку?` и варианты `npm run check`, `npm test`, `Не запускать`. Это уменьшает неоднозначность и позволяет интерфейсу показать кнопки.

## Approval — не то же самое, что вопрос

Вопрос уточняет намерение. Approval подтверждает уже определённое действие. Перед approval агент должен показать точную команду, целевой файл или иной эффект.

```text
Агент предлагает: npm run check
Ожидаемый эффект: только статическая проверка TypeScript
Подтвердить выполнение?
```

## Правило

Никогда не спрашивайте «разрешить ли что-нибудь сделать?». Покажите конкретный объект, команду и последствия. После отказа агент обязан предложить безопасную альтернативу или честно остановиться.

## Практика

Составьте два вопроса: один для выбора варианта реализации, другой — для подтверждения удаления файла. Во втором обязательно укажите точный путь файла.
