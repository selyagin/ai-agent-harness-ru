# Итоговая работа: мини coding agent

## Цель

Соберите CLI-agent harness, который получает задачу, безопасно исследует учебный проект и возвращает проверяемый отчёт. Не стремитесь сразу создать полноценный аналог IDE-агента: важнее сделать границы системы понятными.

## Обязательные компоненты

- `readFile` и `searchText` с проверкой пути и лимитами вывода.
- System prompt с правилом «сначала поиск, затем чтение».
- Чтение `AGENTS.md`, если файл есть в корне проекта.
- Sandbox-интерфейс.
- Политика команд `allow` / `ask` / `deny`.
- `askUser` для неоднозначных решений.
- План действий и финальный отчёт о проверках.
- CLI с обязательным `--task`.

## Сценарий проверки

Запустите задачу: «Найди, где реализована функция поиска, и предложи проверку». Агент должен найти файл, не выходить за рабочую папку, не выполнять опасных команд и перечислить, что он реально проверил.

## Чек-лист

- [ ] `.env` в `.gitignore`.
- [ ] Путь `../` блокируется.
- [ ] Большой вывод обрезается с отметкой.
- [ ] Неоднозначность вызывает вопрос.
- [ ] Команда с побочным эффектом требует approval.
- [ ] Финальный ответ отделяет факты от предположений.

## Критерий готовности

Проект готов, если другой человек может запустить CLI, увидеть понятные этапы работы и убедиться, что агент не получил больше прав, чем ему необходимо.
