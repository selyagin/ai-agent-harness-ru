# Модуль 5. Подагенты

## Зачем разделять роли

Один агент, который одновременно исследует проект, меняет код и запускает команды, получает слишком много прав и быстро заполняет контекст. Подагенты позволяют разделить работу.

## Explorer

Explorer имеет только `search` и `read`. Его задача — ответить кратко: где находится нужный код, какие файлы связаны с задачей, какие риски и какую проверку стоит выполнить. Он не меняет файлы и не запускает shell-команды.

## Executor

Executor получает вывод explorer, план и ограниченный набор tools. Он может предложить изменение, а выполнять действие с побочным эффектом — только после approval.

## Принцип наименьших прав

Каждому подагенту выдавайте лишь необходимое. Если задача — найти обработчик ошибки, explorer не нужен доступ к `writeFile` или `bash`. Это снижает риск и делает поведение понятнее.

## Изоляция контекста

Главный агент не обязан переносить в историю весь разговор подагента. Достаточно структурированного отчёта: найденные файлы, вывод, неопределённость и рекомендуемый следующий шаг.

## Практика

Разделите задачу «исправить ошибку в форме» на запрос explorer и запрос executor. Укажите инструменты и права каждого.
