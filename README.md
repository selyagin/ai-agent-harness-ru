# AI Agent Harness — курс на русском

Самостоятельный практический курс по созданию безопасного AI coding agent с нуля. Текст и примеры написаны на русском; программа вдохновлена Vercel Academy, но не является официальным переводом.

## Как проходить

1. Подготовить Node.js, TypeScript и Git.
2. Собрать безопасные инструменты `read` и `search`.
3. Добавить system prompt, контекст проекта и sandbox.
4. Научить агента задавать вопросы, планировать и проверять результат.
5. Собрать CLI-агента и PDF-версию курса.

## Безопасность

- Не публикуйте API-ключи и `.env`.
- Не выдавайте модели полный доступ к `bash`.
- Действия, изменяющие файлы или сеть, требуют явного подтверждения.
