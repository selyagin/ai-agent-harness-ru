# Модуль 3. Sandbox и безопасное выполнение

## Что такое sandbox

Sandbox — это изолированная среда, через которую агент получает доступ к файлам и выполнению команд. Вместо прямого вызова функций ОС harness работает с единым интерфейсом. Благодаря этому локальную реализацию можно позже заменить на in-memory или облачную без переписывания инструментов.

## Минимальный интерфейс

```ts
type Sandbox = {
  read(path: string): Promise<string>;
  search(query: string): Promise<string>;
  run(command: string): Promise<{ stdout: string; stderr: string; code: number }>;
};
```

## Локально — не значит без ограничений

Локальная sandbox удобна для обучения, но команда выполняется на вашем компьютере. Поэтому не передавайте модели свободный `run(command)`. Сначала разрешайте только команды проверки, например `npm run check`, `npm test` и `git status`.

## Approval

У команды должны быть режимы:

- `allow` — известная безопасная проверка выполняется автоматически;
- `ask` — действие меняет файлы, сеть или окружение и требует подтверждения;
- `deny` — команда запрещена всегда.

Пример: `npm run check` можно отнести к `allow`; `rm -rf`, `curl ... | sh` и команды с неизвестным содержимым — к `deny` или `ask`.

## Практика

1. Выпишите команды, которые в вашем проекте можно считать проверками.
2. Отдельно выпишите команды, меняющие файлы.
3. Не добавляйте `bash` в tools, пока не реализовано правило approval.
