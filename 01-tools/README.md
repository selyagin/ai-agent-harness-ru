# Модуль 1. Инструменты агента

## Цель

Модель не читает файлы сама. Harness даёт ей ограниченные функции. В `src/tools.ts` есть два первых инструмента: `readFile` для известного файла и `searchText` для поиска, когда файл ещё неизвестен.

## Контракт инструмента

Для каждого tool укажите: когда применять, когда не применять, что запрещено, допустимые параметры и пример вызова. Описание — часть безопасности: по нему модель решает, какой инструмент выбрать.

## Почему сначала search

Не читайте подряд десятки файлов. Сначала найдите совпадения, затем изучите только релевантные файлы. Так агент использует меньше контекста и делает меньше лишних действий.

## Почему проверяется путь

`path.resolve` превращает относительный путь в абсолютный. `safePath` после этого проверяет, что итог остаётся внутри рабочей папки. Поэтому `../` не даёт доступа к личным файлам вне проекта.

## Проверка

1. В учебном проекте вызовите `readFile(process.cwd(), 'README.md')`.
2. Найдите слово `agent` через `searchText`.
3. Попробуйте `readFile(process.cwd(), '../secret.txt')`: ожидается ошибка о выходе за рабочую папку.
